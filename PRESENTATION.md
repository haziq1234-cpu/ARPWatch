## Slide 2 - Introduction
ARP stands for Address Resolution Protocol.
It is used to map IP addresses to MAC addresses
inside a local network.

## Slide 3 - Security Problem
Unexpected changes in IP-to-MAC mappings
may indicate suspicious network activity.
Monitoring these changes can help identify
potential network security issues.

## Slide 4 - Project Objectives
- Learn ARP protocol
- Understand IP and MAC mappings
- Study suspicious changes
- Generate timestamped alerts
- Practice Python programming
